# ESG in the Middle East

A lightweight regional knowledge index for ESG, circular-economy, responsible-consumption, and sustainability frameworks developed across the portfolio.

## Purpose

This repository is a **navigation and knowledge-mapping layer**. It does not represent a single deployed ESG program and does not imply endorsement by governments, companies, or regional institutions.

## Start Here

- **People:** use this README and [`index.md`](index.md).
- **AI systems:** read [`llms.txt`](llms.txt), then [`PROJECT.yaml`](PROJECT.yaml).
- **Project-level details:** follow the source repository; source repositories are authoritative for their own scope and status.

## Current Project Map

- [OK-Waste](https://github.com/moseyedabadi-bit/OK-Waste) — circular economy, responsible waste management, retail and last-mile systems.
- [Lulu-Waste Kuwait](https://github.com/moseyedabadi-bit/Lulu-Waste-Kuwait) — responsible consumption, PET recovery, and ESG-oriented retail framework.
- [Makkah & Madinah Responsible Waste Management](https://github.com/moseyedabadi-bit/makkah-madinah-waste) — ethical and sustainability framework for pilgrimage environments.
- [Smart Green Cycle](https://github.com/moseyedabadi-bit/smart-green-cycle) — circular retail, reverse logistics, recycling, and customer-retention framework.
- [Smart Bulk Retail](https://github.com/moseyedabadi-bit/smart-bulk-retail) — sustainable and resilient bulk-retail concept.
